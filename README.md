# Tech Store — Loja de Cursos

Projeto desenvolvido para praticar a criação de páginas web com **HTML5**, **CSS3** e **Bootstrap 5**. A proposta é apresentar uma loja fictícia de cursos profissionalizantes, com uma página de catálogo e páginas individuais para os cursos.

## Sobre o projeto

A **Tech Store** reúne páginas de apresentação de cursos e exercícios de construção de interfaces. O catálogo principal exibe seis opções de cursos:

- Excel
- Planilhas
- Word
- Criação de Sites
- PowerPoint
- Digitação

Cada página de curso apresenta informações como descrição, nível, modalidade, duração e preço.

O repositório também contém uma atividade independente de loja utilizando componentes do Bootstrap, com cards de produtos e imagens temáticas.

## Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo das páginas.
- **CSS3** — estilização e organização visual.
- **Bootstrap 5.3.8** — componentes e classes de layout na atividade da pasta `bootstrap`.

## Como executar

Não é necessário instalar dependências ou configurar um servidor.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Para visualizar a loja de cursos, abra o arquivo `atividade_cursos/index.html` no navegador.
4. Para visualizar a atividade com Bootstrap, abra `bootstrap/index.html`.

Você também pode utilizar a extensão **Live Server** no Visual Studio Code para executar as páginas localmente.

## Observações

Este projeto tem finalidade educacional e demonstra a construção de páginas estáticas. Os botões de compra são elementos visuais de demonstração; não há integração com pagamentos, carrinho de compras ou banco de dados.

## Objetivo de aprendizagem

Praticar a estruturação de páginas HTML, a aplicação de estilos CSS, a organização de arquivos e imagens e o uso de componentes do Bootstrap na criação de interfaces de lojas virtuais.
